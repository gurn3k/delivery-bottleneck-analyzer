Method. Times run from when a PR became ready for review. Review and approval are the final lgtm and approved labels set by Kubernetes' merge bot (Prow). Bots and the PR's own author never count as a response. Medians and p90 only; groups under 10 PRs show — and are never ranked. A PR with more than 3 SIG labels is counted as cross-cutting.

Limits. Labels are a proxy: a PR waiting on a reviewer who is away looks the same as one waiting because the change is hard. Rework is folded into review time. This ranks queues by team and stage, never people.

Built with AI coding agents from a product spec and decision records. Public GitHub data only.
