# 0004: The unit of analysis is team and stage, never a person

**Status:** accepted 2026-10-04

**Decision:** no dashboard view or brief ranks named contributors or reviewers. Logins appear only as PR authors in drill-down links, which GitHub already shows publicly.

**Why:** naming the "slowest reviewer" would be unfair and inaccurate, since a queue reflects capacity and process, not effort. (An earlier version also said Kubernetes maintainers are mostly volunteers; that was never verified and was removed on 2026-10-06.) A good TPM fixes the system, not the person.
